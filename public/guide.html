Orbit brings read-only ICS and CalDAV events to a simple web calendar and your Meta display glasses. Pair once, then let the display refresh automatically.

Open calendar  ↗Open glasses view

Connect the glasses

You’ll need the glasses and a phone or computer online at the same time. No app install or Orbit account is required.

01

Show a pairing code

Open the glasses view on your Meta display and keep it open. Orbit shows a six-digit code that expires after ten minutes.

https://orbit-calendar.henning-orbit-calendar.workers.dev/glasses.html
02

Add your CalDAV account

On your phone or computer, open the calendar settings. Enter your provider’s HTTPS CalDAV address, username, and app password.

Use the provider’s calendar server URL, not the URL of a sync companion app.

03

Pair and leave it open

Enter the code and choose Send calendar to glasses. Orbit checks access, then the glasses show upcoming events and refresh about every minute.

Tip: Choose an app-specific password if your provider offers one. The glasses receive a device token and event data, never the CalDAV password.

Use Orbit in a browser

Connect a calendar

Open Settings and paste a public ICS feed, or enter a CalDAV URL and credentials for a read-only fetch. Choose Sync calendar to load events. The open page refreshes once a minute.

Plan your day

Select a date, move between months, and use Add plan for local reminders. These plans stay in this browser. Export .ics downloads them as a file; Orbit does not write them back to CalDAV.

Built for a light touch

Read-only by design

Orbit reads events from ICS or CalDAV. Your calendar provider remains the source of truth. Local plans are not uploaded.

Credentials stay protected

Browser-only credentials are not saved. When pairing glasses, the CalDAV connection is encrypted before it is stored by Orbit. Disconnect removes the saved pairing.

Quick answers

Where do I find my CalDAV URL?

Check your calendar provider’s setup page. Some providers require an app password. A public ICS URL works for browser viewing, but glasses pairing currently uses CalDAV credentials.

The code expired or was rejected.

Reload the glasses page for a new code, then enter it within ten minutes while both devices are online.

I don’t see any events.

Check the account, server address, and calendar permissions. Orbit needs permission to read the calendar and an internet connection on the glasses.

The glasses view requires a supported display web view with JavaScript and local storage. Compatibility varies by device and calendar provider.
